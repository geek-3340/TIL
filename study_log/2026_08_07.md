### 詳細・補足
**3.学習用のLaravelプロジェクト（Blade）を構築**
Ubuntuで以下を実行
```bash
# Laravelプロジェクト立ち上げ（blade）
laravel new study-app
```
Cursorでプロジェクトを開きターミナルで以下を実行
```bash
# sailのインストール(pgsql)
composer require laravel/sail --dev
php artisan sail:install

# DBをマイグレーション
sail up -d
sail artisan migrate
```

>[プロジェクト作成-Laravel公式ドキュメント](https://laravel.com/docs/13.x/installation)
>[sailの構築-Laravel公式ドキュメント](https://laravel.com/docs/13.x/sail)
