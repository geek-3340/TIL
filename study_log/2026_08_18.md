### 詰まったこと / エラー全文
```php
function myArrayCalc(array $array, callable $func): void
{
    foreach ($array as $value) {
        $func($value);
    }
}

$data = [1, 2, 3];
$result = 0;

myArrayCalc(
    $data,
    function ($value) use (&$result) {
        $result += $value;
    }
);
```
上記における、`use (&$result)`が参照してる親スコープがどこなのか混乱した


### 原因はなんだったか（自分の言葉で）
`use (&$result)`は一見`myArrayCalc()`の`foreach()`内で実行されているため <br>
`foreach()`内が親スコープかと思ったが、このクロージャはあくまでも`myArrayCalc()` <br>
呼び出しに伴って、渡すコールバックを引数エリア内で直接定義してるだけなので、 <br>
ここでの`use()`の参照先はグローバルスコープとなり、`$result = 0;`が渡る。
